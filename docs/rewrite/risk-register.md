# ScalaAPI Rewrite Risk Register

| Risk | Severity | Current state | Required control |
| --- | --- | --- | --- |
| Lease, hold, or ledger double settlement | P0 | Partial | Lease creation reserves against the SQL account under the same per-user lock; completion/abort, operator settle/release, and versioned NUMERIC debit are transactionally idempotent. Immutable held/forwarded/output-started evidence lets TTL release only never-forwarded work; forwarded ambiguity retains its hold, blocks redispatch, and accepts one late settlement or one audited operator decision. Deterministic one-shot hooks exist and a post-settlement-commit crash replay passed; complete the remaining boundary matrix |
| Account, ledger, hold, or Orleans projection drift | P0 | Partial | PostgreSQL `accounting_accounts` is the sole money authority. A globally serialized periodic reconciler checks ledger contiguity, account totals/versions, usage/debits, holds/leases, and Grain projections; it safely repairs terminal holds/stale projections and persists every other mismatch as an incident. Operator decisions are durable and preserved by later scans. Add concurrent multi-Silo evidence, alerts, and future subscription/affiliate effect contracts |
| Redis or embedded cache reintroduced | P0 | Controlled | Official Garnet digest, external TCP probe, dependency scan, no fallback implementation |
| Garnet outage or stale projections | P0 | Partial | Fail-closed readiness, authenticated `scalaapi:v1` rebuild, Gateway deleted-version flush recovery, and usage-triggered API-key invalidation pass; add TLS, multi-client, multi-instance, and deployment restart tests |
| Credential disclosure or weak rotation | P0 | Partial | Envelope encryption, redacted logs/API responses, rotation drill, security scan |
| Provider response and usage differences | P0 | Partial | Deterministic mock JSON/SSE, independent protocol and fault seed groups, model discovery, embeddings, token counting, nested Anthropic/Gemini usage extraction, non-SSE and incomplete-2xx fail-closed handling, exact streaming media-type validation, pollable media, and blocking non-stream/streaming 429/500/timeout/disconnect/malformed/invalid-content-type billing assertions pass. Gateway `be90413` requires terminal SSE events, exact `text/event-stream`, classifies incomplete chunked bodies and client cancellation as non-retryable unknown charge, and the empty-stack gate covers Provider disconnect, disconnect-before-output, streaming malformed usage, invalid content type, actual downstream client cancellation, and streaming rejection release. Direct disconnect still yields 502 or 503 depending exhaustion boundary; normalize the public error model and add final-usage reconciliation, real adapters, golden fixtures, and provider validation |
| Request idempotency replay or fingerprint drift | P0 | Partial | Durable key/fingerprint rows reject duplicate charge and conflict before scheduling; bounded non-stream response replay is implemented; forwarded/output-started ambiguity remains blocked until late settlement or resolution while held expiry safely reopens; one post-commit crash replay passed with one debit; add the remaining boundary and streaming semantics tests |
| Pricing version or decimal precision error | P0 | Partial | Decimal-only business DTOs, fixed-scale Cap'n Proto fields, immutable NUMERIC lease snapshots, Admin publish/close validation, and Platform active-version refresh pass; add provider price adapters and historical backfill tests |
| Payment webhook replay or forged settlement | P0 | Partial | Raw-body HMAC verification, provider/event deduplication, exact order amount/currency checks, paid/refunded transitions, unique credit/refund ledger effects, and pending-event recovery pass; add provider secrets rotation, adapter reconciliation, and exact-boundary crash injection |
| Subscription entitlement or renewal drift | P1 | Partial | One-active subscription constraint, NUMERIC quota grants, expiry transition, and idempotent purchase/cancel/renew events pass; couple provider settlement, quota consumption, renewal workers, and reconciliation |
| Scheduler split-brain or stale sticky route | P0 | Open | Orleans lease ownership, Garnet rebuild, multi-silo failure drills |
| Media bytes lost or unauthorized | P0 | Partial | Provider polling copies bytes to MinIO, stores object key/ETag/size, returns SigV4 presigned access, and Gateway deletion removes stored objects; add object-vs-database reconciliation, restore, and lifecycle cleanup tests |
| Long connection leaks or backpressure | P1 | Partial | Chunked SSE framing, non-SSE rejection, bounded non-stream timeout, pre-body upstream disconnect rejection, zero-length client-write cancellation, terminal-event-gated SSE completion, and incomplete chunked-body disconnect classification pass in Gateway source; Provider-side partial-SSE and actual downstream client-cancellation retention pass in empty-stack smoke; add truncated-stream final-usage/replay, streaming/WebSocket soak, and bounded-buffer metrics |
| Session and auth abuse | P1 | Partial | Hashed rotating sessions, self-service password/profile/delete flows, and revocation checks are implemented; add replay/concurrency tests, API-key revocation/retention assertions, TOTP hardening, Passkey controls, and distributed limits |
| Benchmark or test false positive | P1 | Controlled | Child-report validation and non-zero propagation are implemented; retain CI failure tests |
| Contract source or generated artifact drift | P1 | Controlled | Schema digests match; CI pins the official Cap'n Proto 1.0.2 commit and local `capnpc-csharp` 1.3.118, byte-compares all generated C# output, and an intentional drift probe exits non-zero |
| Cross-repository release gate silently skipped | P1 | Open | The source-owned empty-volume Docker/Podman gate passes locally with process replacement, one Platform crash/recovery, and five isolated billing failures; provision a read-only private Gateway checkout token or a dedicated release repository, then make the exact script blocking in hosted CI |
| Observability gaps | P1 | Open | Projection backlog/retry plus reconciliation incident count, age, unknown-charge, and last-success gauges exist with run/incident Admin queries; add cross-service correlation, alert rules, traces, dashboards, and alert smoke tests |
| Backup, restore, or rolling release regression | P1 | Open | Signed artifacts, measured RPO/RTO, rollback and recovery drills |
