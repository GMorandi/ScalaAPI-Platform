# ScalaAPI Rewrite Risk Register

Active source evidence is Platform `b5586cf`, Gateway `418da3a`, and the
`scalaapi-media-restart-0810` empty-volume gate. Embeddings profiles, Responses
compact, and the media batch list/items boundary pass their source-owned
contracts and exactly-once settlement; broader provider and adapter fidelity
remains a partial-domain risk.

The next active investigation is Images/media per-item reconciliation. Orphan
cleanup, terminal retention, and running-operation restart restore are now
implemented as bounded background/recovery passes, but deployment-scale evidence
remains open.
ScalaAPI's durable media rows and object HEAD reconciler now prove owner-scoped
batch listing, public item projection, and Provider-backed cancellation. Cancel
acknowledgement deliberately retains the unknown-charge hold for reconciliation;
complete per-item batch reconciliation behavior found in Sub2API's batch-image
handlers remains unproven.
These remain explicit release risks.

Current baseline note: Platform `eecaff6` and Gateway `d1e4a85` passed the
source-built `scalaapi-responses-input-items-0810b` empty-volume gate. OpenAI Moderation
response match and upstream-unavailable paths produced redacted audits, warning or
critical alerts, normal NUMERIC settlement, and idempotent replay. The production
endpoint remains HTTPS-only; the smoke HTTP switch is explicit and development-only.
`ContentPolicyPropagationService` now claims independently with `SKIP LOCKED`, while
each publication and Garnet rebuild share a PostgreSQL
advisory lock and reject stale revision overwrite; the pinned Garnet image has Lua
scripting disabled, so the implementation uses its native RESP operations.
`e639b50` also isolates the zero-length `disconnect_before_output` Provider fixture
and the smoke proves a prompt 503 with one retained unknown-charge hold.
`926b98e` adds a process fault hook after policy outbox claim; the smoke kills and
restarts Platform at that boundary and proves the expired claim is reclaimed and
published once. Multi-process ordering and explicit Garnet outage convergence
remain open. The `scalaapi-garnet-rotation-0810` source gate now generates a short-lived
CA/PFX chain, enables server-side Garnet TLS, proves Platform/Gateway CA trust and
DNS identity through readiness, and passes the full provider/restart/reconciliation
matrix with no retained containers. It also rotates a same-CA certificate, rejects
wrong-name and expired bundles, restores the valid certificate, and settles a new
billable request. Partitioned multi-process convergence remains open.
`OpenAiModerationMetrics` now exposes fixed-label classifier counters and a bounded
latency histogram without content, rule, endpoint, or credential labels; the
metrics are process-local and do not yet enforce cross-instance p95/error budgets.
`ModelPricingService` now gives an effective administrative quote precedence over a
later provider refresh, with PostgreSQL-backed test evidence. Remaining risks are
measured production latency/error budgets, credential rotation, separate-process
Garnet propagation, live browser authorization, long-stream soak, and provider/
tokenizer-specific pricing.
